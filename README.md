# Лабораторная работа №2. Классы и объекты в Dart

## Описание проекта
Консольное ToDo-приложение для управления списком задач, написанное на языке Dart. Приложение работает в интерактивном CLI-режиме внутри бесконечного цикла, считывая команды пользователя. Реализован полноценный объектно-ориентированный подход: автоматическая генерация ID внутри класса с помощью статических полей, использование вычисляемых свойств (геттеров) для отслеживания статуса, а также интеграция внешнего пакета для цветного отображения вывода в терминале.

## Запуск
1. Клонировать репозиторий:  
   ```bash
   git clone <URL_вашего_репозитория>
   ```
2. Перейти в папку проекта:  
   ```bash
   cd lab2_todo
   ```
3. Установить зависимости (включая пакет `ansicolor`):  
   ```bash
   dart pub get
   ```
4. Запустить приложение:  
   ```bash
   dart run
   ```

## Ответы на вопросы

### 1. Поле класса (свойство) принадлежит объекту и хранит его уникальное состояние на протяжении всего жизненного цикла этого объекта. Локальная переменная в функции создаётся только в момент вызова этой функции и автоматически уничтожается сразу после завершения её работы.

### 2. Конструктор — это специальный метод класса, который автоматически вызывается при создании нового экземпляра объекта. Он необходим для выделения памяти, первоначальной настройки объекта и обязательной инициализации всех его полей входными параметрами или значениями по умолчанию.

### 3. Аннотация `@override` сообщает компилятору, что мы переопределяем метод `toString()`, который изначально существует в неявном базовом суперклассе `Object`. Если её убрать, код скомпилируется и продолжит работать, однако аннотация защищает от опечаток в названии метода и делает код более понятным и безопасным.

### 4. Обычные поля создаются заново для каждого нового объекта (у каждого объекта свои `id` и `title`). Статическое поле принадлежит самому классу, а не его экземплярам. В программе всегда существует ровно **одна копия** статического поля `_counter`, общая для всех создаваемых объектов класса.

### 5. Нижнее подчёркивание перед именем идентификатора в Dart заменяет модификатор доступа `private`. Оно делает элемент приватным. Приватность в Dart ограничивается не рамками класса, а рамками **конкретного файла (библиотеки)**. Поле `_counter` доступно везде внутри файла `todo.dart`, но защищено от прямого доступа и изменения из внешних файлов.
